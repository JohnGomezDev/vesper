# Design — 001-vesper

Aquí viven las **imágenes de referencia de diseño** de la app. Llegarán más adelante; puede haber varias.

## Uso previsto

- Las tasks de base visual (F1) y de interfaz (F7) deben tomarlas como fuente de referencia.
- Si una imagen contradice el `SPEC.md`, manda el SPEC y se pregunta al dueño.
- Las imágenes no se incrustan en el HTML de producción; sirven como guía de implementación.

## Convención

- Nombres descriptivos en kebab-case, por ejemplo `home-movil.png`, `panel-noche.png`, `selector-noches.png`.
- Si una imagen es de una pantalla o estado concreto, indicarlo en el nombre o en un archivo `notes.md` dentro de esta carpeta.
